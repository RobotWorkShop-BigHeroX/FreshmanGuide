# 《2026 Robot工作坊新生指南》设计规范文档 (Design Specification)

## 1. 文档定位与风格目标
- **读者对象**：湖南大学 Robot 工作坊 2026 级新生（涵盖机械、电气、信息、机器人工程、人工智能等各专业本硕新生）。
- **语言风格**：接地气、真诚温情、学长学姐带路、讲真话与大实话；杜绝假大空官话与生硬说教；融入真实排障案例（如场地喷布反光、机械臂标定）。
- **核心功能**：既是工坊业务、王牌赛项与校企营地的“全景画卷”，更是新生大学前两年的“软硬件+AI技能树、避坑指北与选拔通关指南”。

---

## 2. 章节结构与详细规划

### 【前言】写在前面（学长学姐寄语与答疑引路人）
- **开篇警句**：引用老指南经典名言（“学习的敌人是自己的满足……”），阐述工坊自发、纯粹、互助的极客精神。
- **2026 答疑引路人矩阵（模板占位）**：
  - 分专业方向（自动化/电气、机械/智能车辆、软件/计科、人工智能/机器人工程）列出对接学长学姐。
  - 标注擅长领域（“硬件神”、“视觉消防员”、“算法老手”、“飞控巡检”等）与常驻工训工位、联系方式占位。
- **工坊元老与工训中心导师介绍**：介绍中心指导老师与历届优秀学长，展现团队传承。

---

### 【第一章】工坊业务与竞赛全景

#### 1.1 核心领航赛事（具身智能重点业务，置顶展示）
- **RoboCup 机器人世界杯（中国赛及国际赛）**：
  - **赛项战略转型**：原中型组已停，全面聚焦**人形机器人足球与竞技**。
  - **四大核心研发组职责与技术栈**：
    1. **感知与定位组**：OpenCV/YOLO 目标识别、卡尔曼滤波/粒子滤波融合 IMU 与摄像头、视觉 SLAM/激光 SLAM（ORB-SLAM、Cartographer）、球门/球/对手/自定位。
    2. **策略与决策组**：战术规划、强化学习（PPO/DQN、Gym 环境）、行为树（BehaviorTree.CPP）/有限状态机、A*/RRT 路径规划、攻防传球多机协同。
    3. **运动与控制组**：双足人形运动学/动力学、PID 闭环控制与调参、Pure Pursuit/Stanley 路径跟踪、ROS2 通信、MuJoCo / Isaac Sim 物理引擎动力学仿真。
    4. **通信与系统组**：UDP/TCP 底层通信、GameController 裁判系统接口协议解析、DDS/ROS2 分布式节点通信与时钟同步、局域网网络管理。
    - *(特别声明：原“硬件与调试组”已取消，本次不予招募)*。
- **世界人形机器人运动会**：
  - 前沿人形双足步态规划、全身动力学控制、高动态竞技对抗。

#### 1.2 主力骨干赛事
- **中国机器人大赛专项赛（每年8月，国赛敲门砖）**：
  - 介绍专项赛晋级机制与国赛保底奖项逻辑。
  - (1) **武术擂台赛 - 视觉挑战项目**：
    - 任务：自主寻路、动态避障、激光模块射倒标靶。
    - 技术：Ubuntu + ROS 导航 + OpenCV，NoMachine 远程调试。
    - 避坑实战：工坊场地喷布反光“晃瞎”雷达/深度相机的真实排障案例。
  - (2) **武术擂台赛 - 轮式格斗赛项**：
    - 任务：树莓派+Luby双控，自主登台、避台防跌落、推挤格斗、能量块识别。
    - 技术：软硬件高度结合，Python + C/C++ + SolidWorks 结构件 + 嘉立创 EDA 自制板卡。
  - (3) **智能清洁机器人挑战 - 餐厅3D清洁赛项**：
    - 任务：移动底盘 + 5自由度机械臂，自主导航、餐具回收、垃圾识别分类投放。
    - 技术：ARM Ubuntu + 国产32位单片机底层，ROS-Noetic、Cartographer SLAM、AprilTag 识别、机械臂逆运动学解算。
  - (4) **武术擂台赛 - 仿人格斗**：
    - 任务：双足小型人形机器人动作设计与格斗对抗。
- **中国高校智能机器人创意大赛（6月线上预赛，8月线下国赛）**：
  - (1) **四足机器人（小型组）**：桌面级双机器狗协同作业、危险标志识别、避障与协同搬运。
  - (2) **四足机器人（大型组）**：工业巡检级机器狗，复杂地形越障、野外救援与机械臂末端抓取，高算力自主导航与二次开发。
  - (3) **智能机器人对抗赛 - 轮式机器人**：自主攻防对抗与激光测距博弈。
- **中国机器人大赛常规主力赛项补充**：
  - **乒乓球机器人**：JAKA 机械臂 + LK 电机 + 工业相机 + 裁判盒 UDP 广播。运动学奇异点避让、坐标系标定、代码健壮性、基于裁判盒得分的闭环反馈微调击球策略。
  - *(拓展介绍：全国大学生电子设计竞赛（电赛）及格斗赛参与建议)*。

#### 1.3 训练营矩阵（实训练兵场）
- **校企产教融合训练营（大厂前沿合作）**：
  - 达摩院/Datawhale 乐云具身 SparkEdu：开源机械臂实操、VLA 模型体验部署、全链路开发。
  - 中科云谷具身智能创新实践：聚焦人形机器人开发全链路能力。
  - Datawhale/火山引擎 OpenClaw 百校用虾大会：Agent 智能体环境搭建与进阶开发。
  - 抖音 AI 创变者计划黑客松：高校青年 AI 创意与产品落地。
- **工坊寒假精英训练营（参赛队伍直通车）**：
  - 4 周打卡进阶制：每周提交计划与总结，学长打分计入总评。
  - 考核双轨制：统一基础考核（基础软件/基础硬件二选一） + 进阶技术栈自主选学答辩（开学 PPT / 源码实物答辩）。

### 【第二章】技能树与学长秘籍（2026 AI时代新解）

#### 2.1 基础技能（大一入门必修）
- **软件**：
  - **C语言**：工科基石与11月闭卷小考核唯一科目。学到指针前，重点在基础语法与编程思维，推荐翁恺与黑马程序员网课。
  - **Python**：AI 时代高效胶水语言，快速验证算法、调包与调用大模型接口。
  - **Java（大实话版）**：明确说明工坊比赛用不上，主要供科班同学未来互联网开发岗参考。
- **硬件**：
  - **SolidWorks**：3D 机械结构建模、3D 打印打样与运动仿真。
  - **立创 EDA**：PCB 电路设计、元件选型与电路板打样（自制主控板、电源板、电机驱动板）。

#### 2.2 进阶技术栈（选学与答辩方向）
- **嵌入式开发**：51 单片机底层寄存器逻辑 ➔ STM32（江协科技、铁头山羊，外设驱动与电机底层控制）。
- **Linux / Ubuntu**：双系统与虚拟机配置避坑，常用终端指令速查心法（不死记，靠实操与 AI 查用）。
- **ROS / ROS2**：机器人核心操作系统（推荐 ROS2 Humble/Kilted），鱼香 ROS 一键安装、Nav2 导航、SMACC2 状态机与 BehaviorTree 行为树。
- **CV（计算机视觉）**：OpenCV 核心技能（HSV 颜色空间分割、AprilTag 标签定位、轮廓识别、形态学处理），作为感知“螺丝刀”。
- **AI 与具身智能**：Datawhale 学习地图（Agent 智能体、LLM 应用、Vibe Coding 理念、强化学习蘑菇书）、VLA 具身大模型部署、Isaac Sim / MuJoCo 动力学仿真。

### 【第三章】学习安排与考核选拔（保姆级时间线）
- **10月-11月（打牢基础与小考核）**：专注 C 语言自学，11月下旬线下闭卷机考（语法阅读与代码补全，重在考查自主解决问题态度，高通过率）。
- **12月（期末备考）**：学业至上，全面停训复习期末考试。
- **1-2月（寒假精英营与大考核）**：4 周周计划追踪；统一基础软硬件二选一考核 + 进阶技术自主选学（开学 PPT / 源码实物答辩）。
- **春季开学后（定队与换届）**：组建 2026 赛季主力各战队；管理层（综合部、技术部、宣传部）换届面试与资源倾斜规则。

---

### 【第四章】AI时代兵器库与极客社区
- **编程软件（Power By AI）**：VSCode + Copilot、Cursor、Claude、Antigravity IDE/2.0 等。指导新手善用 Skills、Subagents、Hooks 提效，同时强调**“先懂逻辑，杜绝盲目抄袭”**。
- **现代环境配置**：放弃又大又慢的 Anaconda，主力推荐现代极速 Python 包管理神器 **`uv`**（配置国内镜像源）与 Node.js/npm。
- **极客社区**：GitHub、Linux.do、V2EX、Hacker News、博客园。

---

### 【尾声】学长的大实话与工坊价值观（老版经典灵魂）
- **在工坊保底能得到什么？**（过硬的软硬件工程动手能力、至少一项正规赛项参赛席位）
- **在工坊有追求还能得到什么？**（A 类国赛/世界大赛荣誉、软著专利、大厂校企营地经历、实机操盘机器狗与人形机器人）
- **竞赛项目与保研的残酷真相**：“*绩点是入场券，比赛是上限与面试底气*”，大一大二尽早摸索。
- **我们最看重的品质**：**责任心、靠谱、团队精神高于一切**；坚决杜绝临赛弃赛、精致利己与投机取巧，营造温暖、互助、严肃活泼的极客大家庭。
