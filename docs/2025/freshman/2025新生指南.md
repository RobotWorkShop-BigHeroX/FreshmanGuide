## 一、比赛介绍

本章将介绍 Robot 工作坊所参与过比赛的规则、所需技能、赛程等等。每年规则都会变，甚至比赛也会有裁撤与新增，但参赛所需的技能大致不变，所以下面列出具体参加过的赛项的规则及其所需的技能，以供参考。所需技能会在后续章节具体介绍。

### 1.1 中国机器人大赛专项赛（一般在每年的八月份）

中国机器人大赛专项赛相当于中国机器人大赛暨 RoboCup 机器人世界杯中国赛的预选赛。这是由于参赛队伍较多的部分赛项，需要提前在专项赛筛选出部分队伍，但只要专项赛晋级，在国赛中大概率会有保底三等奖；相应的，参赛队伍较少的新赛项或冷门赛项，直通国赛，但大概率也不会给保底。

有专项赛的赛项在中国机器人大赛中的获奖比例会高一些。比如，武术擂台有专项赛，在中国机器人大赛中的获奖比例大致为一等奖 20%、二等奖 30%、三等奖 40%；而人形机器人赛项没有专项赛，直接参加中国机器人大赛，获奖比例大致为一等奖 20%、二等奖 20%、三等奖 30%（实际获奖比例每年都会根据实际情况有所调整）。

- **赛事规则参考**：[中国机器人大赛专项赛规则页面](http://crc.drct-caa.org.cn/index.php/category/view?id=1239)

#### 重点赛项
1. **武术擂台**（规则 3.1、3.2、3.3）
   - 所需技能：C语言、ROS、Linux、视觉
2. **乒乓球机器人**（规则 11）
   - 所需技能：C语言、Linux、视觉

---

### 1.2 中国机器人大赛暨 RoboCup 机器人世界杯中国赛（每年十一月份左右）

A类赛事，国内影响力最大的机器人赛事，同时也是我们团队重点参加的赛事。

- **RoboCup 赛事规则**：[RoboCup 规则公告](https://rcccaa.drct-caa.org.cn/article_info.php?id=45)
- **机器人大赛赛事规则**：[大赛规则公告](https://rcccaa.drct-caa.org.cn/article_info.php?id=77)

#### 重点赛项
1. **RoboCup 足球机器人比赛（中型组 MSL）**（去年获得全球第一）
   - 所需技能：C语言、SolidWorks、嘉立创EDA、嵌入式、ROS、Linux、视觉
2. **人形竞技全能赛**（规则 10.2，团队长期参与赛项）
   - 所需技能：C语言、SolidWorks、嘉立创EDA、嵌入式、视觉
3. **武术擂台**（规则 8，需先通过专项赛）
   - 所需技能：C语言、ROS、Linux、视觉
4. **智能清洁**（规则 20.1，餐厅清洁）
   - 所需技能：C语言、ROS、Linux、视觉
5. **乒乓球机器人**（规则 21，需先通过专项赛）
   - 所需技能：C语言、Linux、视觉

---

### 1.3 中国高校智能机器人创意大赛（每年六月线上选拔，八月线下国赛）

创意赛在学校属于重点培育赛事，技术难度高。团队保留队伍参加轮式格斗赛项，后续参赛队伍将继续扩充。

- **赛事规则参考**：[智能机器人创意大赛官网](http://www.robo-maker.org/dszq/)

#### 重点赛项
1. **轮式机器人格斗A**（团队老牌传统优势赛项）
   - 所需技能：C语言、SolidWorks、嘉立创EDA、嵌入式、视觉
2. **仿人机器人格斗B**
   - 所需技能：C语言、SolidWorks、嘉立创EDA、嵌入式、视觉
3. **服务机器人竞技**（涵盖 A、B、C 组别）
   - 所需技能：C语言、ROS、Linux、视觉
4. **无人机竞技**
   - 所需技能：C语言、ROS、Linux、视觉

---

### 1.4 中国智能机器人格斗及竞技大赛（每年十一月份举办）

格斗赛规则大多与同年创意赛相似，鼓励大家使用已有研究成果参赛。部分赛项为线上赛，在工坊即可完成评测参赛，便于沉淀技术与积累竞赛经验。

---

### 1.5 全国大学生电子设计竞赛（电赛，非工坊专门序列，仅作技术拓展介绍）

电赛为 A 类赛事，3 人一组参赛，赛期为 4 天 3 夜，每年八月初举办。分为省赛与国赛，逢单数年为全国国赛年。
电赛含金量极高，获奖难度大。嵌入式与模拟/数字电路为必备基本功，赛题方向涵盖电源、信号、控制、仪器等。对于希望深入硬件底层的同学是极好的锻炼平台。

---

### 1.6 全年备赛与梯队时间线

- **年初（寒假至开学）**：通过寒假训练营 + 春季学期开学考核，遴选出主力成员。
- **春季学期（3-5月份）**：确立新一届参赛队伍，开展系统性技术集训。
- **夏季（7-8月份）**：参与创意赛决赛与中国机器人大赛专项赛（选拔赛）。
- **秋季（10-11月份）**：参加中国机器人大赛暨 RoboCup 中国赛线下全国总决赛。
- **冬季（12月份）**：参加机器人格斗赛，启动下一年度技术复盘。
- *注：RoboCup 国际赛及重型全尺寸机器人赛项根据项目进度另行排期。*

## 二、技能介绍与资料推荐

### 2.1 基本技能

基本功的练习至关重要。学会编程语言的基础语法并不复杂，难点在于养成良好的编程习惯与模块化架构设计能力；机械结构设计与电路板绘制均注重动手实操与工程经验。

#### 2.1.1 软件编程

建议所有成员首先扎实学习 C 语言，这是工科与机器人嵌入式开发的根基，直接与第一阶段考核挂钩。

- **C 语言**：掌握 C 语言后，再接触 C++、Python 等其他语言将水到渠成。
  - 推荐网课 1：[黑马程序员 C 语言零基础到精通全套视频教程](https://www.bilibili.com/video/BV1Xa4y1k7LU/)
  - 推荐网课 2：[浙江大学翁恺 C 语言程序设计](https://www.bilibili.com/video/BV1dr4y1n7vA/)
- **Python**：开发高效，库生态丰富，常用于算法验证与人工智能方向开发。学完 C 语言后能够迅速掌握基本语法。
- **高级语言定位**：工坊当前主要以 C/C++ 与 Python 为主，Java 与纯移动端语言在当前机器人赛事中基本不作要求。

#### 2.1.2 硬件设计

硬件主要包含机械结构与电子电路两部分：

- **结构设计**：使用 SolidWorks 进行三维机械零件与装配体建模。
  - 推荐教程：[SOLIDWORKS 教学精品教程 (B站播放量领先课程)](https://www.bilibili.com/video/BV1iw411Z7HZ/)
- **电路设计**：使用嘉立创EDA（便捷快速、元器件库完善）或 Altium Designer 进行原理图绘制与 PCB Layout。
  - 推荐教程：[零基础入门 PCB 设计 - 嘉立创EDA专业版教程](https://www.bilibili.com/video/BV1At421h7Ui/)

---

### 2.2 进阶技术方向

进阶技术基于良好的编程与软硬件基础，重在工程实战应用与自驱动探索。

#### 2.2.1 嵌入式微控制器开发
- 入门建议从 51 单片机或 STM32 微控制器开始。51 有助于深入理解微机底层寄存器与硬件电路交互；STM32 拥有完善的 HAL 库生态，应用广泛。
- **网课推荐**：
  - [江协科技 51 单片机入门教程](https://www.bilibili.com/video/BV1Mb411e7re/)
  - [江协科技 STM32 入门教程](https://www.bilibili.com/video/BV1th411z7sn/)
  - [铁头山羊 STM32 入门教程](https://www.bilibili.com/video/BV11X4y1j7si/)

#### 2.2.2 Linux 操作系统
- 机器人开发主流运行环境，具备高效的多任务调度与外设通讯管理。
- 建议使用 VMware 虚拟机或双系统安装 Ubuntu 20.04 / 22.04 LTS 版本。
- 重点熟练掌握基础命令行操作与开发环境配置工具。

#### 2.2.3 ROS (Robot Operating System)
- 机器人的分布式通信中间件与开发框架，广泛用于路径规划、自主导航、传感器融合与运动学控制。
- **学习资源**：
  - [古月居 · ROS 入门 21 讲](https://www.bilibili.com/video/BV1BP4y1o7pw/)
  - [Autolabor ROS 机器人入门课程](https://www.bilibili.com/video/BV134411171n/)
  - [鱼香ROS 一键安装与环境配置指南](https://fishros.com/)

#### 2.2.4 计算机视觉 (CV)
- 在机器人赛事中主要落地于目标检测、颜色识别、人脸/二维码识别、空间位姿解算与图像去畸变。
- Python OpenCV 库是快速验证视觉逻辑的首选工具。
- 推荐教程：[黑马程序员 10小时学会图像处理 OpenCV 教程](https://www.bilibili.com/video/BV1Fo4y1d7JL/)

## 三、学习安排与选拔机制

为了兼顾不同同学的学术基础与发展节奏，工坊制定如下阶段性考核与培养路线：

### 10月 - 11月：基础素养小考核
- **学习目标**：夯实编程底座，重点学习 C 语言基础语法（可暂不涉及复杂指针高级操作，鼓励了解 C++ 基础面向对象语法）。
- **考核范围**：C 语言基础知识与程序逻辑。
- **考核形式**：闭卷线下编程，携带个人电脑至指定机房独立完成，严禁违规作弊。
- **选拔目的**：筛选具备自主学习意愿与解决基础问题能力的同学，通过后正式纳入工坊预备队员。

### 12月 - 寒假：自主深耕与冬训营
- 期末期间优先备战学校课业，寒假期间组织线上寒假训练营。
- 围绕实战项目开展 SolidWorks 机械建模与立创EDA 电路设计专项演练。

### 春季开学后：队伍重组与正式建制
- 结合寒假实践成果与技术答辩，确立正式竞赛梯队成员。
- 综合部、技术部、宣传部等管理运维架构同步吸纳骨干成员，提供综合实践与赛事重点支持。
